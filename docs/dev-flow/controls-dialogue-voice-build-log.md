1. 「可以增加左右旋轉的按鈕嗎」「左右旋轉功能可以融合進去同心圓裡面嗎？」→ 使用者選：**推左右就轉向**。

## 2. 搖桿（`src/input/FirstPersonController.ts`）

- 同一個同心圓：往上推前進、往下推後退、往左右推原地轉身，斜推邊走邊轉；放開就停。
- 轉身最快每秒 1.3 rad（約 75°），柔和不暈。每一軸有死區：往上推不會順便轉、往旁邊推不會順便走。
- 圓盤上加了 ▲▼↺↻ 提示（不攔截觸控）；讀屏說明與設定裡的說明文字同步更新。點地面前往、拖曳看向、設定裡的單次按鈕都保留。
- 不再能「橫著走」（原本搖桿是全方向平移）。

## 3. 對話畫面（`src/styles.css`、`src/ui/GreetingUI.ts`）

- 對話時整個畫面蓋一層半透明暮色（`rgb(31 42 51 / 35%)`，沒有模糊），公園的操作暫停；選完回到公園才收起。
- 卡片從畫面一半開始，上方留給說話的人（臉和表情看得到）；選項多時卡片自動往上移，整張卡片都在畫面內。
- 對方的台詞像對話泡泡；選項是一排大按鈕（圖示在上、文字在下，最多 3 欄，至少 80 px 高）；「幫助」「再看一次」並排在下面。
- 標題（例如「打招呼」）只留給讀屏軟體。頂部「暫停」「返回安全區」在暮色之上，隨時可按。

## 4. 語音（已做好播放與產生工具；**音檔尚未產生**）

- `src/dialogue/VoiceLines.ts`：從四個情境列出要唸的句子（人物台詞用該人物的聲音、提示由旁白唸），去除重複後共 **70 句**；檔名由「說話者＋文字」決定，改了文字就是新檔案。
- `src/ui/VoicePlayer.ts`：只播放 `public/assets/voice/` 裡預先產生的靜態檔（依 `manifest.json`）；一次只播一段，換下一步、暫停、返回安全區、關閉語音時立即停止；沒有音檔時什麼都不做。App 不呼叫任何語音 API，前端沒有金鑰（Q5）。
- 對話：每一步自動唸一次（先人物台詞、再旁白）；有語音時「再看一次」變成「再聽一次」（重播）。設定裡新增「語音」開關（預設開）。
- 產生工具 `tools/voice/generate-voice.mjs`：用專案的 vite 讀出同一份台詞清單，逐句呼叫 Gemini TTS（預設 `gemini-2.5-flash-preview-tts`），用 ffmpeg 轉成約 40 kbps 的 AAC（.m4a）並統一音量，寫入 `manifest.json`。只產生還沒有的句子；遇到額度限制會等一下再試，失敗就停下，下次執行接著做。金鑰只從環境變數 `GEMINI_API_KEY` 讀取，不寫入任何檔案。
- 聲音（可用環境變數覆寫）：小安 Puck、小宇 Fenrir、小晴 Leda、媽媽 Sulafat、旁白 Achernar；語氣依節點表情（例如「有點不好意思，溫和」），一律請它說慢一點、音量平穩。
- `--dry-run` 已在雲端環境執行：列出 70 句，未呼叫 API。

**目前狀態：音檔未產生（未驗證）。** 這個雲端工作階段沒有 `GEMINI_API_KEY`。使用者需在雲端環境設定加入這個環境變數（新的工作階段才會讀到），或在自己的電腦執行：

```bash

```

## 4a. 改用裝置內建語音（使用者選擇）

- 原因：這個雲端環境沒有 `GEMINI_API_KEY`；可直接套用的開源 TTS 模型下載點（Hugging Face）與線上語音服務在雲端環境被擋，而且多數不適合放進靜態網站。使用者選「裝置內建語音」。
- 做法：瀏覽器內建的 Web Speech API（`speechSynthesis`），不用套件、不連外部服務、沒有金鑰、不送出任何資料。優先用台灣國語（zh-TW）聲音，沒有就用其他華語聲音（不用粵語）。
- 用音高與速度區分說話者（裝置沒有真正的小孩聲音）：小安 1.5／0.9、小宇 1.35／0.95、小晴 1.7／0.9、媽媽 1.1／0.85、旁白 1／0.85（音高／速度），音量 0.9。
- 有預先產生的 Gemini 音檔時優先播音檔，其他句子才用裝置語音；§4 的產生工具保留，日後有金鑰仍可使用。
- 停止規則不變：換下一步、暫停、返回安全區、關閉語音時立即停止；被取消的那句結束時不會接著唸下一句（換代計數）。關閉語音時按鈕回到「再看一次」。
- **變更 Q5**：原本只用 Gemini 預先生成音檔；現在預設用裝置內建語音，Gemini 音檔變成可選。實際聲音品質依裝置與系統語音而定。
