# 每日語音 routine 建置紀錄（2026-10-22）

## 授權與決策

使用者選定 Sadaltager B 溫和慢速、+2.5 半音作為小男孩聲音，要求製作全部語音及每日 routine。查證官方文件後已說明 Free Tier 與付費 Tier 1 不同；使用者明確選擇「沿用 Tier 1 預付金鑰，每天最多生成 5 句，接受小額扣款」。先前 npm ci、檢查與 commit／push 的授權持續有效，遊戲發布仍另確認。

## 實作

- 小安／小宇／小哲：Sadaltager，精確沿用已試聽 B 版的生成指示，升高 2.5 半音，保持原生成速度。小晴／小芸維持 Zephyr A、0.85 速度、+2.5 半音；成人／旁白維持既有聲線。
- 實際語音清單 226 句：小安 3、小宇 5、小哲 4、小晴 2、小芸 5、媽媽 48、阿公 4、旁白 155。生活練習已包含支持情境；補齊街區「你留在這裡。」變體。按角色輪流製作。
- main 放每日排程，UTC 09:23 執行（台灣時間 17:23），預設手動只預覽。資料保存於 codex/daily-game-voice，沒有發布分支推送或網站部署。
- 每天最多 5 次請求，失敗也計數，採太平洋日期；每次先將預留額度推到遠端，才發請求。來源 WAV 與處理結果各自保存；後製失敗或改參數時沿用原音。完成全部音檔後不再呼叫 API。
- 429／空音訊不即時重試；401／402／403／404 暫停整個生成，單一來源 3 次失敗後列人工檢查。Git checkpoint 只可推專用分支，保存失敗不呼叫 API。
