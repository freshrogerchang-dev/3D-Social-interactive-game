# 公園場景細節建置紀錄（2026-10-15）

分支 `main-uv12jr`。由 Claude Code 雲端工作階段執行。

## 1. 使用者要求

「把場景弄好看一點 更多細節」。

## 2. 做法

新增 `src/scene/ParkDetails.ts`，由 `ParkEnvironment` 擁有並在 `dispose()` 時一起釋放。全部是**靜態**幾何：不會動、不發光、不閃爍；沒有粒子、後製或即時陰影。以 InstancedMesh 繪製（約 20 個 draw call）。沒有新增套件或外部素材：葉片沿用既有 CC0 葉子貼圖，草葉與地面色塊貼圖由程式產生。

| 細節 | 位置 |
|---|---|
| 外圍樹籬一圈（留出入口、後方步道、東西向步道開口）與 8 叢圓形灌木 | x ±13、z −9.6／+11 |
| 樹籬內側花圃：泥土、低矮葉叢、柔和顏色的花（同色成群） | 樹籬內側 0.95 m |
| 靜止的鞦韆、沙坑、第二張長椅、野餐桌 | 可走範圍外（左右兩側） |
| 6 盞路燈（不發光）、2 個垃圾桶、入口柱頂與空白木牌、石頭 | 入口、後方、步道兩端 |
| 遠景：約 60 棵由小團樹冠組成的樹、22 棟淡色建築輪廓（交給霧變淡） | 45–88 m 外 |
| 天空：地平線與霧同色、往上漸藍；8 朵靜止的雲 | 天空球 240 m |
| 草地：淡淡的深色區塊（打破貼圖重複）與 1600 叢小草（低細節 600） | 避開步道、溜滑梯、沙坑 |

設計限制：

- **會擋路的設施都放在可走範圍（|x|、|z| ≤ 8）之外**，不需要新增碰撞，也不影響走向小安、小宇、小晴、媽媽的路線。可走範圍內只有貼地的小草與地面色塊。
- 顏色 HSL 飽和度 ≤ 0.6（材質與每個 instance 顏色都有單元測試），並沿用場景的飽和度上限 shader。
- 「設定 → 環境細節：低」同時減少樹葉與草叢。

## 4. 限制

- iPhone 實機 FPS 與載入時間未量測；SwiftShader 截圖不能代表實機效能。若實機變慢，可先把「環境細節」調為低。
- 遠景樹與建築是簡化造型，靠霧變淡；近看與前景寫實的樹風格不完全一致。
- 需要 preview server 的 S4／S5 瀏覽器檢查（`browser-check.mjs`、`s5-runtime-browser.mjs`、`s5-extended-browser.mjs`）本次未執行（啟動 preview 需使用者同意），標示**未驗證**。
