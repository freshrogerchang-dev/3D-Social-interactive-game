## 2. 每台裝置的安全路徑

1. 載入頁面，確認公園地面、兩個安全按鈕與單一 canvas；記錄任何 console 錯誤。
2. 按「暫停」：畫面停住，出現「休息一下」；等待後仍保持休息。按「繼續」才恢復。
3. 按「返回安全區」：一次操作顯示安全區休息畫面；沒有確認視窗、倒數或評價語。
4. 按「結束本次」：canvas 移除；按「重新開始」只建立一個新場景。重複 20 次。
5. 鍵盤依序測 Tab、Shift+Tab、Enter、Space、Esc；每個可見動作可達，焦點可見且不被工具列遮住，無鍵盤陷阱。滑鼠與平板點按另測。
6. 切到其他分頁／其他 App，再回來：應停在休息畫面，不能自動恢復。另測背景載入頁面，回前景後要自行重新開始。
7. 可用 DevTools 停用 WebGL：錯誤面板的重試／結束，以及常駐暫停／安全區仍有效。真實 GPU 的 context loss 僅由熟悉 DevTools 的成人測試者操作；不可用就記未驗證，不以模擬事件代替。
8. 橫直向切換、瀏覽器工具列展開／收合、安全區 inset；所有動作至少 64 CSS px，短視窗可捲動到面板最後的按鈕。

## 3. 文字與螢幕報讀器

- 使用瀏覽器實際的 200% 文字設定；另做 200% 頁面縮放與等效 320 CSS px 重排，三者分別記錄。root font-size=32px 或 CDP pageScaleFactor 不能替代原生文字縮放。
- 改文字間距：行高 1.5、段落後 2 倍字級、字距 .12em、詞距 .16em。確認標題與全文、按鈕文字、焦點可見且無內容損失。
- Windows NVDA＋Firefox／Chrome；macOS／iPadOS VoiceOver＋Safari：記錄讀序、按鈕名稱、休息／安全／錯誤／結束標題是否被理解，焦點轉移是否提供足夠上下文，返回場景後是否仍可找安全控制。可及樹的正確名稱不能替代這項實測。
- 3D 畫面目前為無互動裝飾背景，stage 為 aria-hidden。未來新增任務或 NPC 資訊時須重新驗證 DOM 替代資訊。

## 4. 效能與資源

production 版本，接電狀態與電源模式保持一致；記錄 GPU、螢幕刷新率、網路與快取條件。暖機 10 秒後，量測 60 秒×3，列各次平均 FPS、p95 frame time。分開量測冷快取／暖快取載入；記錄 navigation timing、資源總位元組、場景首次可用時間。60 FPS 是待實機驗證的目標，不由 SwiftShader 結果宣布達標。

重建資源：在相同休息／結束狀態於 0／5／10／15／20 次擷取 heap、DOM／監聽數與 RAF；若 heap 持續增加，進一步比較 retained objects／retainer paths，不能只數 canvas。renderer.info 與 GPU 資源需另有可觀測工具，現有正式程式沒有公開 engine，這兩項先記未驗證。
