# 公園的動態感：人物閒置動作、排隊的小朋友、吹泡泡 建置紀錄（2026-10-16）

分支 `main-uv12jr`，基準 `246de7d`（卡通人物）。由 Claude Code 雲端工作階段執行。

## 1. 使用者要求

「可以讓 NPC 有動態感嗎？另外像是排隊溜滑梯可以加上一些小朋友排隊，有人在吹泡泡等」。

這改變了原本「人物只在明確互動時做單次動作、沒有自動循環動作」的設計（S3 建議，非使用者決定）。依使用者要求加入閒置動態，但保留低刺激的選項：**所有閒置動態都受「人物動作」開關與系統「減少動態」控制，關閉時全部靜止、泡泡隱藏**；啟動時就套用使用者的設定（以前只在設定改變時才套用）。

## 2. 做法

### 人物閒置動態（`src/npc/SeatedNPC.ts`、`src/npc/CartoonFace.ts`）

| 動態 | 幅度／節奏 |
|---|---|
| 呼吸（上衣微微變寬） | ±1.2%，約 3.4 秒一次 |
| 頭慢慢左右看、輕微歪頭 | 轉頭 ≤ 0.12 rad（約 7°），8.5 秒一循環 |
| 眨眼 | 約 0.18 秒，每 2.5–6 秒一次 |
| 偶爾看向旁邊再看回來 | 看 1.5–3 秒，間隔 3–7 秒 |
| 站著的人手臂微擺 | ≤ 0.05 rad |
| 小安坐在長椅上晃腿 | ≤ 0.22 rad，左右交替，2.2 秒一次 |
| 小宇手上的球輕輕往上拋再接住 | 3.5 公分，1.6 秒一次 |

- 每個人的節奏依 id 錯開（可重現，不同步），沒有亂數閃動。
- 對話中的揮手、點頭優先；結束後回到閒置動態。暫停時不更新，恢復第一幀 delta 0 不前進。
- 新增選項：`idle`（可關閉）、`y`、`bench`、`reach`（雙手往前扶著）、`prop: 'bubbles'`。坐姿的小腿、襪子、鞋子掛在膝蓋軸點上以便晃腿。

### 背景小朋友（`src/scene/ParkScene.ts` 的 `extras`）

不能對話、不出現靠近提示，只有閒置動態；各有個人空間（加入場景的障礙物）。

| 人物 | 位置 |
|---|---|
| 溜滑梯平台上準備溜下去的小朋友 | 平台上（高 1.33 m），面向滑道 |
| 扶著梯子的小朋友 | 梯子前 |
| 吹泡泡的小朋友 | 長椅右後方、步道旁（出發點往前看得到），不在走向任何人物的路線上 |

溜滑梯的兩位排在小晴**前面**，玩家仍是「排在小晴後面」，排隊情境的台詞不用改。

### 泡泡（`src/npc/Bubbles.ts`）

18 顆半透明淡藍泡泡，從泡泡棒慢慢飄上去（每秒約 0.1–0.25 公尺）、稍微變大，最後 0.6 秒內縮小消失；出生時從 0 慢慢長大，不會突然出現或爆開閃一下。由吹泡泡的人物驅動，材質由人物擁有並釋放。

- 溜滑梯上的小朋友不會真的溜下去（只有閒置動態）。
- iPhone 實機效能未驗證；需要 preview 的 S4／S5 瀏覽器檢查未執行。
